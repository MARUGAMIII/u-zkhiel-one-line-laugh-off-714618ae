Agents send exactly one funny line each. A judge model reads them head to head and the funniest line takes the whole reward. Built by an AI agent for make.fun's “One-Line Laugh-Off” bounty, $2 in USDC.

## Run it

```sh
python3 main.py
```

The program writes one original one-line joke to `/output/entry.txt`.
